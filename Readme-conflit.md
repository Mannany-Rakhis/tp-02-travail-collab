# Exercice : résoudre un conflit Git

Ce fichier sert à pratiquer la résolution d'un conflit de fusion.

1. Créez deux branches à partir d'une même version.
2. Modifiez cette phrase différemment dans chaque branche.
3. Fusionnez les branches pour déclencher un conflit.
4. Choisissez le contenu à conserver, supprimez les marqueurs Git (`<<<<<<<`, `=======`, `>>>>>>>`), puis validez la résolution.

Phrase à modifier dans chaque branche :

> Cette ligne sera modifiée différemment dans chaque branche.
